# Tasker New

**Purpose**: Create new business need folder and set as active business context.

## Process

1. **Create business folder** `docs/business/YY-MM-DD-[business-name]/`
2. **Create structure**:
   - `business.md` (empty, for business-analyst)
   - `features/` (empty folder)
3. **Set as active business** in `.claude/active-business.txt`
4. **Create global backlog** `docs/backlog.md` if first business
5. **Launch business-analyst**

## Success Criteria
- Business folder created with proper structure
- Active business set for future commands
- Ready for business analysis
